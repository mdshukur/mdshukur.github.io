In recent years I have relied on JustWatch to quickly see ratings and where to watch a movie. I used to use MovieLens (run from a university) and tried it again and found it is a much better predictor of movies I will like.

| Key Requirement | MovieLens.org | JustWatch | Metacritic | IMDB |
|---|---|---|---|---|
| Personalized movie ratings | Excellent | No | No | No |
| Ratings by others | users of MovieLens | Yes | users of Metacritic | users of IMDB |
| Where to Stream | No | Yes | Yes and theaters |  |
| Information | Movies - TMDb | Movies, TV | Movies+TV+Games etc. | IMDB |
| Share lists | Yes | Yes | ? | ? |
| UI | Web, WebApp | App, TV app, Web | Web, Android | App, Web |
| Ad heavy | No ads | Yes | Yes | Yes |
| When to use | Find movies I would like | Finding streaming sources | Critics + streaming | Detailed movie info |
